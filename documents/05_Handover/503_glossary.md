## Project Management

**MoSCoW**
A prioritisation method: Must have, Should have, Could have, Won't have. Used to decide which goals are reduced first when time runs out.

**Story Points**
A unit for estimating effort in Scrum, assigned using the Fibonacci sequence (1, 2, 3, 5, 8, 13). Calibration used: 2 story points ≈ 1 hour of work.

**Sprint**
A fixed-length iteration in Scrum. This project uses three four-week sprints and a closure phase.
